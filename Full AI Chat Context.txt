● It's built: a C# app plus a small Firefox extension. The app side is tested
  with fake Twitch payloads, but the extension has not been run against real 
  Twitch yet, so the first live prediction is the real test.

  To run it

  1. Start the window with ./run.sh from the Prediction Bot folder.
  2. In Firefox, open about:debugging#/runtime/this-firefox, click Load 
     Temporary Add-on… and pick extension/manifest.json.
  3. Open or reload a Twitch channel. The status line should turn purple and
     read ● Hooked: <channel>.

  Firefox drops temporary add-ons when it closes, so step 2 has to be repeated
  after each restart.

  What it does

  - Hook: the extension listens in on the data the Twitch page already receives
    and forwards anything about predictions to the app. It is read-only and
    sends nothing to Twitch.
  - Database: every prediction and its choices go into SQLite at
    ~/.local/share/PredictionBot/predictions.db.
  - Odds: each choice is sorted by its share of the pool at close: low odds
    under 30%, medium, high over 70%. I picked those cut-offs; they are two
    constants in Stats.cs.
  - Best pick: it also tracks crowd favourite, underdog, and Option 1/2 by
    position, then names the group with the highest expected return (minimum 5
    bets).
  - Bayesian part: each group gets a win rate with a 95% interval and a
    "P(profit)" figure. It starts from the assumption that the crowd prices
    things fairly, so a group only looks profitable once results say so.
  - Window: small, dark grey with purple and white, with a channel filter and a
    card for the prediction currently open.

  What to know

  - Untested live: if the status line shows "Hooked" but a prediction resolves
    and nothing is recorded, the listening code in extension/hook.js is the
    place to look. Tell me and I'll dig in.
  - .NET install: there was no .NET on the machine, so I installed the .NET 10
    SDK into ~/.dotnet (no sudo; delete that folder to remove it).
  - Firefox only: the extension is written for Firefox, since that is the
    browser installed.
  - Payout caveat: payouts are fixed when a prediction locks, so the ratio you
    bet at is not the ratio you get paid at.

  The README.md in the folder explains each column in the table.
